# Sample visual assets

The local demo is seeded into Firestore by a deliberately emulator-only script. These are real licensed surface images, not fabricated Cloudinary upload results. Production uploads use the signed Cloudinary workflow. All sample material names, specifications and prices are explicitly illustrative, not claims about a real supplier's product.

The library's surface names do not establish geological classification, supplier origin, finish or performance; sample metadata remains illustrative.

## Typography

DM Sans and DM Serif Display are self-hosted Google Fonts, under the SIL Open Font License. CSS aliases Atlas Sans and Atlas Serif are internal font-family names only, not original font designs. Original sources:

- https://github.com/google/fonts/tree/main/ofl/dmsans
- https://github.com/google/fonts/tree/main/ofl/dmserifdisplay

Font license texts are included alongside the downloaded font files. No font-provider request is needed at runtime.

The earlier green UI experiment included self-hosted Barlow Condensed (OFL),
aliased as Mineral Display. Those licensed files remain in the repository but
are not loaded by the current neutral stone experience, which uses DM Sans and
DM Serif Display. Original Barlow source/license:
https://github.com/google/fonts/tree/main/ofl/barlowcondensed.

No Resn/Pioneer images, fonts, models or proprietary code are reused. The Corn
Revolution site informs scroll choreography and cinematic transitions; the new
WebGL slab/countertop geometry and motion are authored within this application.
